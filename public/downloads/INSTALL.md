# Install Keep the Sentence in Chromium

1. Download and extract `keep-the-sentence-extension.zip`.
2. Open `chrome://extensions` in Chromium.
3. Turn on **Developer mode**.
4. Choose **Load unpacked**.
5. Select the extracted folder.

The extension now appears in Chromium. On a regular web page, select a phrase
and choose **Keep this sentence** from the right-click menu.

Keep the Sentence stores your saved phrases in this browser. It does not need
an account or a network service.
