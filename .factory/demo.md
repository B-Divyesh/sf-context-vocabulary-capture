# Demo sandbox

Open `/demo` (or `/?demo=1` for direct catalog links) to seed three realistic vocabulary captures. The persistent banner says “Demo — sample data, nothing is saved.” It offers **Reset demo** and **Start for real**.

Demo records use the `demo:keep-the-sentence:vault` local-storage namespace. Real records use `keep-the-sentence:vault`. The Start for real control overwrites the demo vault with an empty encrypted vault before leaving. The demo has no network calls and works from the shipped assets after the first local load.

The sample includes English, Spanish, and German phrases with source context, a source link, and learner meanings. Use **I remembered it** to record a review or **Export CSV** to download the records.
