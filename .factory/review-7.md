## Demo and sandbox

**PASS.** Clicking **Try it with sample data** once opened `/demo` with a populated review board already visible at 390 px. It showed the realistic English phrase **“quietly held,”** two source sentences, its meaning, a source link, CSV export, and all three English/Spanish/German records.

The persistent banner reads **“Demo — sample data, nothing is saved”** and provides **Reset demo** and **Start for real**. Marking the phrase remembered advanced the review to **“recoger el hilo.”** Reset restored **“quietly held”** and `3 total`. During demo, only `demo:keep-the-sentence:vault` and `demo:keep-the-sentence:device-key` existed. Start for real removed both and left the real namespace empty. The registered exit test separately seeded a real encrypted vault and confirmed that demo exit preserved it byte-for-byte. The direct demo request log contained only same-origin requests.

## Structure, privacy, and visual check

- `/`, `/demo`, `/privacy`, and `/terms` return 200; an unknown URL returns the designed 404. `robots.txt` and `sitemap.xml` are present.
- Public routes have one h1, `lang="en"`, main landmark, metadata, canonical, social image, favicon, skip link, shared header, and Privacy/Terms footer links.
- Same-origin links, sample source pages, install guide, and download resolve. Keyboard activation, 390 px layout, route focus and announcement, Back behavior, and serious/critical Axe checks pass in the suite.
- The response CSP is a header and includes `frame-ancestors`. There are no third-party fonts, scripts, analytics, provider keys, or runtime AI endpoints. Demo requests were same-origin only.
- The warm paper, ink, cobalt, tangerine, serif/sans, printed-rule, and halftone reading-margin system matches `.factory/design.md` and is visibly product-specific rather than a generic SaaS template.

## Missed leverage

No additional AI, sync, or import feature is required by the available scope. CSV export is present and tested. Automatic meaning generation would send reading text outside the local-first workflow and is not implied by the product’s core capture-and-review job. No decorative AI feature or embedded provider key was found.
